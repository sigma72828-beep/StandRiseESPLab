# StandRise ESP Lab (демо)

Учебный Android-проект на Kotlin. Показывает отдельное меню и локальную демонстрационную ESP-сцену с переключателями ESP, Names, Distance, Boxes и цветом.

**Ограничение:** приложение не подключается к StandRise Rework и не считывает игровые данные. Для ESP в самой игре нужен разрешённый API/SDK или исходники тестовой игры.

## Сборка APK
1. Установите Android Studio.
2. Откройте папку `StandRiseESPLab` через **Open**.
3. Дождитесь Gradle Sync. Если Android SDK Platform 35 не установлен, установите его через SDK Manager.
4. Выберите **Build → Build APK(s)**.
5. APK будет создан в `app/build/outputs/apk/debug/app-debug.apk`.

Если Gradle предлагает обновить плагины, сначала попробуйте собрать проект с указанными версиями.
